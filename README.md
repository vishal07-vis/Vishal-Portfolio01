# Vishal Raj — React Portfolio

A responsive React + Vite portfolio inspired by the dark/purple design reference and populated from the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Customize

- Main content: `src/main.jsx`
- Styling: `src/styles.css`
- Resume: `public/resume.pdf`
